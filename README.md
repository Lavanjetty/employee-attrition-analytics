# Employee Attrition Analytics Dashboard

Interactive machine learning and data mining dashboard built with Gradio, Scikit-Learn, Plotly, and Apriori.

## Modules
1. **Overview**: Key attrition metrics, distribution pie charts, and comparative evaluation.
2. **K-Means Clustering**: Unsupervised employee grouping, 2D PCA projection, and elbow/silhouette analysis.
3. **Classification Comparison**: Decision Tree vs. Random Forest comparison across Accuracy, Precision, Recall, F1-Score, and ROC-AUC with confusion matrices.
4. **Association Rule Mining**: Apriori algorithm discovering workforce factor co-occurrence with interactive support vs confidence plots.
5. **Attrition Risk Prediction**: Interactive risk scoring and gauge for individual employee profiles.
