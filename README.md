## Modules
1. **01 · Overview**: Total workforce counts, attrition distribution (Plotly donut chart), and model evaluation comparison.
2. **02 · K-Means Clustering**: Unsupervised employee grouping, 2D PCA projection scatter plot, and inertia/silhouette analysis.
3. **03 · Classification Comparison**: Decision Tree vs. Random Forest comparative study with confusion matrices and performance metrics (Accuracy, Precision, Recall, F1, ROC-AUC).
4. **04 · Association Rule Mining**: Apriori algorithm discovering workforce factor co-occurrence with interactive support vs confidence plots.
5. **05 · Attrition Risk Prediction**: Interactive individual employee profile scoring with risk gauge indicator and threshold alerts.
